# Auto Crafting Table (NeoForge 1.21.1)

Блок-верстак с ванильным интерфейсом крафта и панелью автокрафтов,
которая забирает ингредиенты из соседних сундуков и складывает результат обратно.

## Сборка (локально)
1. Установите JDK 21 и Gradle 8.10+.
2. `gradle build` — готовый jar появится в `build/libs/`.

## Сборка на GitLab
В репозитории уже есть `.gitlab-ci.yml` — pipeline соберёт jar автоматически,
файл появится в разделе Artifacts (вкладка Build -> Pipelines -> job -> Browse artifacts).

## Использование
- Обычный клик — ванильный интерфейс верстака (сетка 3x3, книга рецептов).
- Shift + клик — панель автокрафта: выложите рецепт в сетку 3x3 и нажмите
  «Добавить крафт». В списке до 6 автокрафтов с кнопками удаления (X)
  и немедленной сборки (>).
- Каждые 5 секунд блок автоматически крафтит сохранённые рецепты,
  забирая ингредиенты из сундуков на всех 6 сторонах и возвращая
  результат в них же.
- Рецепт блока: воронка + красный факел + красная пыль (см. рецепт в игре).

## Текстура
Замените `src/main/resources/assets/autocraftingtable/textures/block/auto_crafting_table.png`
(16x16) и `textures/gui/auto_craft_screen.png` (256x512) своими файлами и пересоберите мод.

## Креативная вкладка
Все предметы мода вынесены в отдельную вкладку «Верстак автокрафта»
в креативном инвентаре.
